## Leetcode solutions

A repo for practicing and learning data structures and algorithms via direct
leetcode questions and general exploration

Top level folders are explicit leetcode solutions primarily in python and rust.
Generally shows progression from brute force solution to something reasonably
efficient.

algos/ folder are not leetcode specific but just try to implement specific
algorithms in a leetcode style fashion, probably in a language unsupported on
leetcode like zig or omcaml.

data-structures/ folder are not leetcode specific but aim to implement various
data structures useful in software engineering

dynamic-programming/ folder specifically for dp practice and related leetcode
questions
